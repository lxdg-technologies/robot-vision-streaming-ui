# AGENTS.md

## Required Shared Reading

Before making changes in any robot repository, every agent must read and follow the canonical shared robot repository docs on GitHub:

- https://github.com/lxdg-technologies/robot-shared/blob/main/AGENTS.md
- https://github.com/lxdg-technologies/robot-shared/blob/main/ARCHITECTURE.md
- https://github.com/lxdg-technologies/robot-shared/blob/main/DEPLOYMENT.md

These shared repository docs are mandatory context for every agent session. Do not treat them as optional reference material.

If a local `robot-shared` checkout or `shared/` submodule is present, agents may use it as a convenience only after confirming it points to the same GitHub repository and current intended revision. When in doubt, use the GitHub URLs above.
